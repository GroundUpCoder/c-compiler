# tests/bench — generated-code performance benchmark (todos/0186)

Measures the speed of code **generated by compiler.js** on a CPU-bound
vendor workload, as the before/after regression gate for codegen work
(inlining, offset folding, CSE, …). This is the number that must move.

```
node tests/bench/run.js
```

Typical output (the last line is the paste-into-a-log result):

```
BENCH sameboy(SuperMarioDeluxe.gbc) | cc 5.697 ms/frame | clang 1.049 ms/frame | 5.43x | sum OK | 281051 B wasm, 120084 instrs (code 234546 B)
```

## What it does

- Builds the headless SameBoy GBC core (`sameboy_bench.c` + the same
  `vendor/sameboy` source list the OS binary uses, minus SDL) with
  compiler.js, and — when available — with clang via the external
  `cc2wasm` driver, into `build/bench/`.
- Times `node host.js <wasm> <rom> <N>` for N = 200/600/1000 frames,
  best-of-3 each, and reports the **slope** ms/frame over the 800-frame
  span, so process startup and V8 tier-up cancel out of the number.
- **Correctness interlock**: every run prints a framebuffer checksum.
  The harness FAILS (exit 1) if reps disagree (nondeterminism), if the
  cc and clang builds disagree at any N, or if the sum diverges from the
  committed `baselines.json` entry for that ROM — so a miscompile can
  never masquerade as "faster".
- Deterministic no-wall-clock proxies for the cc build: wasm file size,
  code-section size, and a static instruction count (fail-loud decoder —
  an unknown opcode drops the proxy loudly instead of miscounting).

## Inputs (both optional — missing input skips, never fails)

- **ROM** (gitignored, copyrighted — NEVER commit one): drop a `.gb`/
  `.gbc` into `vendor/gameboy/roms/` or pass `--rom=PATH`. The baselined
  ROM is `SuperMarioDeluxe.gbc` (`baselines.json` keys by ROM sha256; an
  unknown ROM runs fine and prints the entry to add). No ROM → explicit
  SKIP, exit 0 — a fresh checkout or CI is never broken by this harness.
- **clang comparison**: probes `~/git/clang-simplified/cc2wasm`
  (override with `--clang=PATH`). Absent → cc-only run, noted skipped.

Flags: `--reps=N` (wall-time repetitions, default 3), `--skip-build`
(reuse `build/bench/*.wasm`).

## Deliberately NOT a tests/run.js suite

The ROM dependency makes this opt-in and informational: it is not part
of `tests/run.js all` or any `--diff` mapping (`tests/bench/` maps to no
suite in the RULES table). Run it manually around any codegen change and
paste the BENCH line into the close-out log.

Pre-inlining baseline (2026-07-15, image of main at todos/0186 close):
**cc 5.70 ms/frame vs clang 1.04–1.05 ms/frame (~5.5x), 281051 B /
120084 instrs**. Future workloads (doom/quake timedemo) can join as
additional `*_bench.c` + a second measure() block if a second signal is
ever needed — SameBoy is the priority signal.
