# 0057 — win32: gdi32 drawing subset (CPU → shm)

- **Status**: open
- **Depends**: surface protocol (`SURFACE_*`, exists), freetype (exists, `/bin/term`)
- **Design**: `todos/WIN32.md`

## Goal

The GDI drawing subset, software-rendered into an shm surface — the CPU
drawing foundation every user32 window paints through. This is the DWM
redirection model (CPU draw → shm → `0055` GPU composite), **not** a
fallback: GDI is a CPU rasterizer by definition.

## Plan

- **Device contexts**: `GetDC`/`ReleaseDC`, `BeginPaint`/`EndPaint` (an
  `HDC` over the surface SAB), `CreateCompatibleDC`/`CreateCompatibleBitmap`
  (memory DCs).
- **Objects**: `CreatePen`/`CreateSolidBrush`/`CreateFont`, `SelectObject`,
  `DeleteObject`, stock objects. GDI leak discipline (every object freed).
- **Shapes**: `Rectangle`, `Ellipse`, `RoundRect`, `FillRect`,
  `LineTo`/`MoveToEx`, `Polygon`/`Polyline`; pen/brush/`ROP2`.
- **Text**: `TextOut`/`ExtTextOut`/`DrawText` via freetype (share
  `/bin/term`'s glyph path); `SetTextColor`/`SetBkColor`/`SetBkMode`;
  `GetTextExtentPoint32`.
- **Blits**: `BitBlt`/`StretchBlt`/`PatBlt`; DIB create/access
  (`GetDIBits`/`SetDIBits` — the CPU-bits access ported apps assume).
- **Clip/coords**: client rects, simple clip regions
  (`IntersectClipRect`).

## Acceptance

- A Petzold-style `WM_PAINT` sample (shapes + text) renders bit-exact
  headless (shm golden) and correct in-browser.
- Leak check: repeated paint cycles free every GDI object.
