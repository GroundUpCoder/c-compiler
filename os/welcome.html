Welcome to gucOS

NetSurf — a real browser engine, compiled to WebAssembly, running in your OS-in-a-tab.

Browse files — and the network

This browser speaks file:, data:, http: and https: urls, and JavaScript is on (put enable_javascript:0 in ~/.netsurf/Choices to turn it off).

Your home folder directory listings are pages too

There is no address bar: follow links, or open a url from a terminal — netsurf https://example.com.

Keys

Alt+← / Alt+→history back / forward
Backspaceback
PageUp / PageDown / wheelscroll
Home / Endtop / bottom of the page

Opening pages

Double-click any .html file on the desktop or in the file manager, or run netsurf /path/page.html from a terminal.
